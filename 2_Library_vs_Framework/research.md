# Library vs. Framework Research

## 1. Core Differences
- **Library**: A set of helper functions or classes that you call to perform specific tasks. You retain control of the application flow.
- **Framework**: A structured skeleton that defines the application architecture. You follow the framework's rules, and it calls your code (Inversion of Control).

## 2. Technical Examples
*   **CSS**: Library (Animate.css) vs Framework (Bootstrap/Tailwind).
*   **JavaScript**: Library (jQuery) vs Framework (React/Angular).
*   **Java**: Library (Apache Commons) vs Framework (Spring).
*   **PHP**: Library (Guzzle) vs Framework (Laravel).
*   **Python**: Library (Requests) vs Framework (Django/Flask).
